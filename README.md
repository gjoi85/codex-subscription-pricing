## 官方路线为什么卡住国内用户

价格不是问题，付款才是。

ChatGPT 和 Codex 的官方订阅走的是国际支付通道，国内银行发行的 Visa/Mastercard 在这类场景里被拒的概率不低。被拒的原因通常不是余额不够，而是发卡地区、账单地址、支付通道和风控环境综合判断的结果。你去银行问，客服也只会告诉你「卡是正常的」。

于是国内用户面前通常摆着三条路：

1. 自己搞定海外信用卡、账单地址和网络环境，走官方订阅，价格最便宜，但前期折腾成本高；
2. 找代充或买成品号，便宜、快，但账号可能不是你的，聊天记录不一定私密，出问题几乎没有售后；
3. 用第三方代订阅平台，保留自己的账号，用微信或支付宝付款。

以 ChatGPT Plus 为例，大致步骤是：在 ChatGPT 官网选好套餐、确认账号、复制页面上的登录状态信息，回到平台粘贴、确认账号邮箱、填支付信息，最后微信扫码付款。订阅生效后，用的还是你自己的账号，聊天记录和 Projects 都留在原地。

## 从付款到 Codex 跑起来

买完之后还有几步，很多人是在这里卡住的。Codex 本身是免费工具，「购买」买的其实是它背后的模型算力。

1. **确认订阅状态。** 付款成功后回到 ChatGPT 页面，看账号是否已经显示 Plus 或对应档位。第三方记录里出现过订单显示「完成」但 ChatGPT 仍是免费版的情况 [3]，所以这一步别跳过。
2. **安装 Codex。** 官方提供桌面应用（macOS 和 Windows）、IDE 扩展和命令行版本，下载安装都不花钱 [7]。
3. **选择登录方式。** 在终端执行 `codex login`，会给你两个选项：用 ChatGPT 账号授权，或者用 API key。个人开发者日常写代码，选前者。
4. **查额度。** CLI 里可以用 `/status` 看还剩多少用量 [7]。
5. **需要修复时配合平台。** 如果订阅中途失效，平台可能会提示你重新上传当前的 Session，用来重新关联原有订单 [3]。

## 订阅额度和 API key，是两套账

这是 Codex 计费里最容易算糊涂的地方。同一个工具，两条付费逻辑完全不相干。

**ChatGPT 账号登录**走订阅加额度的模式：固定的月费，套餐内包含一定用量限额，超了再买 credits 续。支出封顶可控，而且云端功能（自动代码审查、Slack、GitHub 集成）只有这条路才有 [7]。

**API key 登录**没有月费，按实际消耗的 token 实时扣费。账单事后才知道，波动大，但不受套餐的 5 小时窗口和每周上限约束。适合 CI/CD、自动化脚本、共享环境这类机器调用场景 [7]。

还有一层变化需要知道：Codex 从 2026 年 4 月 2 日起对 Plus、Pro、Business 改用基于 token 的计费方式，4 月 23 日扩展到 Enterprise；在此之前是按消息或按 PR 的平均费率估算 [8]。这意味着同样一个任务，消耗多少额度取决于它读了多少上下文、写了多少输出，以及缓存命中率。

所以「Plus 够不够用」这个问题没有统一答案。第三方分析给出了一个有用的参照：典型的 GPT-5.5 任务消耗 5 到 45 个 credits，最轻的修补和最重的重构之间差了大约 9 倍 [8]。同一个 US$20 的套餐，对不同的人会呈现出完全不同的宽松程度。

## 让额度更耐用的几个习惯

这部分不是玄学，官方自己的建议里就能找到 [8]：

- **精简提示词。** 指令写清楚，别夹带无关内容，每一轮少发一点输入 token。
- **控制 AGENTS.md 的体积。** 这个文件每次任务都会完整加载一遍，写得太啰嗦等于给每个请求加税，而不只是大任务受影响。
- **关掉用不到的 MCP server。** 每一个都会往上下文里加开销。
- **把日常活儿交给便宜模型。** 需要强推理的任务才用旗舰模型。
- **利用缓存输入。** 重复使用的上下文成本约为普通输入的一成，这是整套体系里最大的省钱杠杆。

把这五条做到位，同一档套餐下月度消耗差出一倍不稀奇。

## 谁适合走代订阅，谁不适合

**适合：**
- 手里只有国内银行卡，官方页面反复拒付；
- 想保留自己的 ChatGPT 账号，不接受共享号或成品号；
- 主要是个人写代码、做副业项目，停一两天不影响交付；
- 想先按月试一档，确认 Codex 真的能进入自己的日常工作流再考虑长期。

**不适合：**
- 团队项目要求订阅连续可用、不能中断；
- 账号里存着不能外泄的代码或客户资料；
- 已经能顺畅完成官方支付，那没有任何理由绕路。

真正省事的做法是先买最短的周期。不是为了省钱，而是先用一个月确认 Codex 在你的实际工作里到底有没有用。用不上，损失的是一顿外卖钱；用上了，再回头看三个月套餐的月均价格才划算。
